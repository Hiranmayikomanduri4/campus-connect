# 🏫 Campus Connect

**Campus Connect** is a smart campus communication and management platform designed to bring students, faculty, and campus administrators together in one centralized digital platform.

It provides a convenient way to access campus information, communicate with different stakeholders, manage activities, and improve the overall campus experience.

## 🎯 Problem Statement

In many educational institutions, campus-related information is distributed across different platforms and communication channels. Students may struggle to find important announcements, events, academic information, and other campus resources in one place.

Faculty and administrators also need an efficient way to communicate with students and manage campus activities.

**Campus Connect** aims to solve this problem by providing a centralized and user-friendly digital campus platform.

---

## 💡 Solution

Campus Connect brings important campus services and information together in a single web application.

The platform is designed to:

* 📢 Improve campus communication
* 🎓 Connect students and faculty
* 📅 Provide access to campus events and activities
* 🔔 Display important announcements
* 📚 Organize campus-related information
* 👥 Provide role-based experiences for different users
* ⚡ Make campus interactions faster and more convenient

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Hiranmayikomanduri4/campus-connect.git
```

### 2. Navigate to the project

```bash
cd campus-connect
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure environment variables

Create a `.env` file based on `.env.example`.

Add the required Firebase configuration values.

**Do not commit private credentials or secret keys to GitHub.**

### 5. Start the development server

```bash
npm run dev
```

The application will be available through the local development URL provided by Vite.

---

## 📦 Build for Production

To create a production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## 🔒 Security

Campus Connect uses Firebase services for authentication and application functionality.

Sensitive credentials should be stored using environment variables rather than directly inside the source code.

The `.env` file should **not** be committed to GitHub.
